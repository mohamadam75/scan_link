# 🚀 scan_link — جمع‌آوری و بررسی روزانهٔ کانفیگ‌های VPN

این پروژه کانفیگ‌های عمومی VPN/Proxy را از چند منبع جمع‌آوری می‌کند، کانفیگ‌های پشتیبانی‌شده را با هستهٔ Xray اجرا می‌کند و درخواست HTTPS را از داخل تونل بررسی می‌کند و نتیجه را هر روز به‌صورت خودکار به‌روزرسانی می‌کند.

## ✨ امکانات

- دریافت کانفیگ‌ها از منابع عمومی ثبت‌شده در فایل `sources.txt`
- حذف کانفیگ‌های تکراری
- نمونه‌گیری پایدار از کل مجموعهٔ کانفیگ‌ها برای جلوگیری از آزمایش صرفاً کانفیگ‌های ابتدای یک منبع
- اجرای کانفیگ‌های پشتیبانی‌شده با Xray و ارسال درخواست HTTPS واقعی از داخل تونل
- انتشار فقط کانفیگ‌هایی که آزمون تونل واقعی را می‌گذرانند (حداکثر ۱۵ مورد)
- اجرای خودکار هر روز ساعت **۷ صبح به وقت ایران**
- امکان اجرای دستی از بخش Actions در GitHub

## ⏰ زمان‌بندی و اجرای دستی

گردش‌کار روزانه برای ساعت **۰۳:۳۰ به وقت UTC** تنظیم شده که برابر با **۰۷:۰۰ صبح به وقت ایران** است. ممکن است GitHub اجرای زمان‌بندی‌شده را با کمی تأخیر آغاز کند.

برای اجرای دستی، وارد [بخش Actions](https://github.com/mohamadam75/scan_link/actions) شوید، گردش‌کار **Daily VPN source monitor** را انتخاب کنید و روی **Run workflow** بزنید.

## 🧪 روش بررسی

کانفیگ‌های پشتیبانی‌شده (VLESS، VMess، Trojan و Shadowsocks) به تنظیمات Xray تبدیل می‌شوند، Xray اجرا می‌شود و یک درخواست HTTPS به `https://www.gstatic.com/generate_204` از داخل تونل SOCKS5 محلی ارسال می‌شود. فقط درخواست‌های موفق وارد فهرست نهایی می‌شوند؛ اگر کمتر از ۱۵ مورد سالم پیدا شود، فهرست کوتاه‌تر خواهد بود. فرمت‌های تبدیل‌نشده عمداً حذف می‌شوند. این آزمون از سرور GitHub انجام می‌شود، نه از داخل ایران.


۱. دریافت داده‌ها از منابع عمومی تنظیم‌شده  
۲. استخراج فرمت‌های پشتیبانی‌شده و حذف موارد تکراری  
۳. تلاش برای برقراری اتصال TCP به هر سرور با مهلت کوتاه  
۴. حذف تکرار سرورها از فهرست نهایی تا چند نام متفاوت از یک آدرس، جای فهرست را پر نکند
۵. قبول فقط اتصال‌هایی که هر ۳ تلاش TCP موفق باشند، بیشینهٔ زمان اتصال حداکثر ۱۲۰۰ میلی‌ثانیه و اختلاف سریع‌ترین/کندترین تلاش حداکثر ۵۰۰ میلی‌ثانیه باشد؛ سپس رتبه‌بندی و انتشار ۱۵ مورد

**اتصال سریع TCP به معنی کارکرد قطعی VPN نیست.** هر سرور سه بار آزمایش می‌شود؛ هر سه تلاش باید موفق باشند، بیشینهٔ زمان اتصال باید حداکثر ۱۲۰۰ میلی‌ثانیه و نوسان بین تلاش‌ها حداکثر ۵۰۰ میلی‌ثانیه باشد. این آزمایش، اتصال کامل از طریق تونل پروکسی را بررسی نمی‌کند و سرعت اندازه‌گیری‌شده از سرورهای GitHub لزوماً نشان‌دهندهٔ سرعت از داخل ایران نیست.

## 📡 وضعیت اپراتورها و موقعیت سرورها

در حال حاضر اجرا روی زیرساخت GitHub انجام می‌شود و به شبکهٔ همراه اول، ایرانسل یا مخابرات متصل نیست. بنابراین پروژه نمی‌تواند صادقانه اعلام کند کانفیگی روی یک اپراتور مشخص کار می‌کند، مگر آن‌که آزمایش از همان شبکه انجام شود. همچنین کشور یا موقعیت سرور باید از منبع معتبر مکان‌یابی بررسی شود و نباید حدس زده شود.

فایل‌های اپراتورها فعلاً ۵ گزینه از رتبه‌های ۱ تا ۱۵ را به‌صورت موقت تقسیم می‌کنند؛ این تقسیم‌بندی به معنی آزمایش یا سازگاری تأییدشده با اپراتور نیست. برای رتبه‌بندی واقعی هر اپراتور، باید آزمایش‌گرهایی متصل به همان شبکه‌ها راه‌اندازی شوند و عملکرد کامل تونل VPN را آزمایش کنند.

## ⚠️ نکات امنیتی و محدودیت‌ها

- کانفیگ‌ها و اشتراک‌ها متعلق به منابع ثالث هستند و ممکن است هر زمان از کار بیفتند.
- کانفیگ‌های ناشناس را قابل‌اعتماد فرض نکنید و اطلاعات شخصی یا رمزهای خود را در آن‌ها وارد نکنید.
- ممکن است نسخهٔ فعلی ابزار همهٔ فرمت‌ها یا همهٔ فایل‌های منابع را پشتیبانی نکند.
- برای اجرای خودکار، GitHub Actions باید در مخزن فعال باشد.

## 🛠️ اجرای محلی

به Python 3.12 و هستهٔ Xray نیاز دارید؛ گردش‌کار GitHub Actions هستهٔ Xray را نصب می‌کند. آزمون‌های واحد استخراج و تجزیهٔ کانفیگ نیز در هر اجرای Workflow اجرا می‌شوند.

```bash
python -m unittest discover -s tests -v
python monitor.py
```
